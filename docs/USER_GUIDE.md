# RunBeat 跑步节拍器 · 使用文档

RunBeat 是一款**面向减肥人群**的跑步节拍器应用：通过稳定的步频节拍与
「快走/慢跑交替」的燃脂循环训练，帮助你保持高效燃脂节奏、科学减重。
支持**基础节拍**与**循环训练**两种模式，后台/锁屏持续运行，并内置自动版本更新。

**项目源码**：https://github.com/Sunrisies/runbeat.git

---

## 1. 快速开始

1. 安装 App，打开后默认进入「**基础节拍**」模式
2. 设置目标步频（如 180 BPM）→ 选择音色 → 点「**开始节拍**」
3. 听节拍、看脉冲动画，跑起来跟上节奏
4. 顶部左侧显示当前版本号（如 v1.1.1）

## 2. 基础节拍模式

### 2.1 步频调节（BPM）
- 范围 **120 – 200 BPM**，支持 **1 BPM 细调**
- **滑动条**：拖动滑块精准调整，滑块下方实时显示当前 BPM 值
- 修改后立即生效；若正在运行，声音会马上切换到新步频并从第 1 拍重新开始

### 2.2 快捷预设
| 预设 | 说明 |
|---|---|
| 160 慢跑 | 入门燃脂慢跑节奏 |
| 180 配速 | 标准配速跑 |
| 190 冲刺 | 间歇冲刺 |
| **我的预设** | 点「保存当前」把当前 BPM 存为个人预设，下次一键调用 |

### 2.3 节拍音色
| 音色 | 特点 |
|---|---|
| 咔嗒 | 清脆短促（重音 1.5kHz / 轻音 1kHz） |
| 哔声 | 柔和长音 |
| 木鱼 | 木质敲击感 |
| **跑步节拍** | 参考跑步节拍音效（**重音≈2.38kHz / 轻音≈727Hz**），更贴近实际跑步节奏 |

- 每 **4 拍第 1 拍为重音**（音调更高、更响），方便数小节
- **音量**滑块：0 – 100%

### 2.4 运行控制
- **开始节拍**：开始运行，第 1 拍立即发声
- **暂停 / 继续**：中途暂停，继续时保持小节拍序
- **重新开始**：从第 1 拍重新计数
- **重置**：停止并清零

### 2.5 节拍可视化
- 橙色/主题色**脉冲圆**：每拍跳动
- **重音拍**：橙色 + 外扩光环
- 下方 **4 个节拍指示点**：显示当前处于小节第几拍

## 3. 循环训练模式（燃脂跑走交替）

> 减肥推荐：**快走与慢跑交替**能长时间维持中高强度、提升燃脂效率，避免全程跑步过早疲劳。

### 3.1 模式切换
顶部「**基础节拍 | 循环训练**」切换。循环模式独立运行，不影响基础模式。

### 3.2 间隔设置
- **工作(分钟)** / **休息(分钟)**：分别设置，范围 **1 – 60 分钟**，精确到分钟
  - 工作 = 慢跑/快跑阶段（节拍器响）
  - 休息 = 快走/恢复阶段（静音，保持走动不站停）
- **快捷组合**：1跑1走 / 1跑2走 / 2跑1走，一键应用
- 参数自动保存，下次进入自动加载上次配置

### 3.3 工作步频
设置跑步阶段节拍器的 BPM（同基础模式调节方式，仅滑动条）。

### 3.4 循环流程
```
工作(节拍器响) → 休息(静音) → 工作 → 休息 → …（每完成一轮工作，轮次 +1）
```
- **状态卡**：显示「工作中/休息中」、第几轮、剩余时间与进度条
- 阶段切换语音播报：**「开始」/「休息」**
- 每阶段**最后 5 秒**：语音倒数 **「五、四、三、二、一」** + 界面大字倒计时
  （优先使用系统文字转语音；不可用时自动使用内置语音，离线可用）

### 3.5 控制
- **开始循环** / **暂停 / 继续** / **终止**
- 暂停/继续保留当前阶段剩余时间

## 4. 后台与锁屏运行

- 开始节拍或循环后，以**前台服务**运行：锁屏、切后台**节拍不中断**
- 通知栏显示运行状态（可下拉控制 暂停/继续/停止）
- 需要通知权限：首次开始时 App 会请求（用于后台持续显示运行状态）

## 5. 版本更新

### 5.1 自动检测
每次启动 App 自动检查新版本；发现更新时弹出提示。

### 5.2 手动检查
主界面右上角「**检查更新**」；无更新/失败会给出提示。

### 5.3 更新弹窗选项
| 选项 | 行为 |
|---|---|
| **立即下载** | 后台下载新版本，显示进度，完成后自动引导安装 |
| **暂不下载** | 关闭弹窗，下次启动重新检测 |
| **不再提示** | 该版本不再打扰；**更高版本**仍会正常提示 |

### 5.4 下载与安装
- 下载中：应用内进度弹窗（百分比 + 渐变进度条），退到后台下载不中断
- 下载完成自动拉起安装器；如未开启「安装未知应用」权限，会引导你去设置页开启，返回后自动继续安装
- 安装权限只需开启一次

## 6. 减肥训练建议

| 目标 | 建议组合 | 说明 |
|---|---|---|
| 新手入门燃脂 | **1跑1走** × 20-30 分钟 | 快走 1 分钟 / 慢跑 1 分钟交替，保持走动不站停 |
| 提升燃脂效率 | **1跑2走** × 30-40 分钟 | 延长快走恢复，维持总时长，适合新手进阶 |
| 突破平台期 | **2跑1走** × 20-30 分钟 | 增加跑步占比，提升强度刺激 |

- **步频建议**：慢跑 160-180 BPM 较易维持；想提高节奏可加到 180-190
- **燃脂要点**：全程保持走动（休息阶段快走而非站立），让心率稳定在中高强度区间
- **循序渐进**：每周增加 10% 时长，避免急于加量导致受伤
- 具体方案请结合自身情况，必要时咨询运动/医疗专业人士

## 7. 常见问题

**Q：为什么修改步频后按钮变成「重新开始」？**
运行中修改 BPM 会立即应用新步频并从第 1 拍重启，让节奏变化清晰可感。

**Q：锁屏后节拍会停吗？**
不会。前台服务 + 唤醒锁保证后台/锁屏持续运行。

**Q：倒计时语音没声音？**
优先使用系统文字转语音（需在手机「文字转语音」设置中启用引擎与中文语音包）；
未开启时自动使用**内置语音**（离线），正常情况下一定有声音。

**Q：怎么知道有没有新版本？**
启动自动检测，或点右上角「检查更新」；界面左上角显示当前版本号。

**Q：安装更新提示「需要安装权限」？**
点「打开设置」→ 开启「安装未知来源应用」→ 返回 App 自动继续安装（只需一次）。
